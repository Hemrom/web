## Cara Update Manual

Jika ingin mengubah profil sekolah lagi:

### Via Admin Panel:
1. Login ke admin panel: http://localhost:3000/admin
2. Klik menu "Profil Sekolah"
3. Edit informasi sekolah
4. Upload logo sekolah (jika ada)
5. Klik "Simpan"

### Via Script:
```bash
node update_profil_sekolah.js
```

## Logo Sekolah

Logo yang Anda berikan sudah disiapkan. Untuk mengupload logo:

1. Login ke admin panel
2. Masuk ke menu "Profil Sekolah"
3. Upload file logo di bagian "Logo Sekolah"
4. Logo akan otomatis muncul di navbar dan footer
